# assets/

本目录存放 README 与对外页面引用的**静态品牌资产**。

> ⚠️ **视觉定稿归属**：当前文件为**技术占位资产**（保证 README 结构完整、链接不破图），
> 最终视觉设计由**设计定稿**。定稿后替换同名文件即可，README 无需改动。

---

## 文件清单

| 文件 | 用途 | 引用位置 | 规格 |
|---|---|---|---|
| `logo.svg` | 方形图标（仓库头像 / npm 页图标） | 不直接引用，供平台使用 | 256×256 |
| `logo-readme.svg` | README 顶部主视觉横幅 | `README.md` / `README.en.md` 首屏 | 960×640（3:2） |
| `logo-wordmark.svg` | 纯文字标（浅色/深色背景通用） | 备用 | 720×160 |

---

## 设计要点（供设计定稿参考）

| 项 | 建议 |
|---|---|
| 主色 | 钉钉蓝 `#1677FF`（与钉钉品牌一致，表明数据来源平台） |
| 辅助色 | `#0B5FD9`（渐变暗端）、`#FFFFFF`（前景） |
| 母题 | **表格网格**——直指"AI 表格"这个核心对象 |
| 禁忌 | 不得使用钉钉官方 Logo 本体（避免隶属关系误读）；见下方"非官方声明" |
| 深色模式 | SVG 内嵌 `prefers-color-scheme`，浅色背景与深色背景均可读 |

---

## 非官方声明（重要）

本插件是**非官方社区集成**，与钉钉（DingTalk）、DeepSeek 均**无隶属或背书关系**。

因此：

- ❌ 不得直接使用钉钉官方 Logo 或商标作为本插件标识
- ❌ 不得使用 DeepSeek 官方 Logo 暗示官方关系
- ✅ 可以用钉钉品牌色表达"数据来自钉钉"
- ✅ 可以在文字中说明"包装钉钉官方 `dws` CLI"

商标与第三方组件声明详见 [../THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。
