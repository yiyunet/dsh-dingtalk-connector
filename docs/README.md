## 写作约定

本仓库文档遵守三条约定，与 [CONTEXT.md](../CONTEXT.md) 的术语表一致：

1. **每条技术结论标明来源档位**：**官方原文** / **实测** / **推测**。推测可以写，但必须显式标注。
2. **禁用模糊措辞**："一般来说""应该是""我记得" 一律不用。
3. **已知限制明示，不掩饰**。例如定时器的进程内语义、`base search` 的 `hasMore` 误报，
   都在文档里直接写明，而不是等使用者踩坑。

> 为什么这么较真：本插件有几个概念**用一个词就会被误解**（例如"定时任务"其实不是云端定时），
> 误解会直接导致使用者按错误预期排故障。措辞精度在这里是功能，不是文风。
